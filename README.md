
# Federal Income Tax Calculator (2025)

## Project Overview
A Python desktop application that estimates federal income tax for single filers using 2025 tax brackets.

## Features
- Interactive graphical interface built with Tkinter
- W-2 and freelance income calculations
- Business expense deductions
- Simplified self-employment tax calculations
- Adjusted gross income (AGI)
- Standard deduction and simplified QBI deduction
- Estimated federal tax refund or balance owed
- Input validation and error handling
- Clear All button

## Technologies
- Python
- Tkinter
- Federal tax calculations

## How to Run
1. Install Python 3.
2. Download tax_app.py.
3. Run: python3 tax_app.py

## Limitations
This application is an educational tax estimator, not tax preparation software. It currently supports simplified single-filer scenarios and does not implement all IRS tax rules, credits, deductions, or exact tax table lookups.

## Purpose
Developed as an accounting and programming portfolio project to demonstrate tax research, financial calculations, and Python application development.
